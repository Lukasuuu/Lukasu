# @bookme/mobile

BookMe mobile app built with Expo SDK 52 and Expo Router v4.

## Stack
- Expo SDK 52
- Expo Router (file-based routing)
- React Native 0.76
- NativeWind v4 (Tailwind for RN)
- TanStack Query
- Zustand
- Expo Secure Store / Local Auth / Notifications

## Scripts
- `pnpm start` — Start Metro bundler
- `pnpm android` — Run on Android
- `pnpm ios` — Run on iOS
- `pnpm web` — Run on web

## Structure
- `app/` — Expo Router screens
- `src/components/` — Shared UI components
- `src/hooks/` — TanStack Query hooks
- `src/stores/` — Zustand stores
- `src/lib/` — Query client and utilities
